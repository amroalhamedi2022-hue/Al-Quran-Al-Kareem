## أداة مراجعة بشرية تعمل دون إنترنت
بعد نجاح workflow `official-source-staging.yml` الأحدث، نزّل artifact باسم `UNAPPROVED-Hafs-604-PNG-for-human-review` وافكّه كاملًا في مجلد محلي. افتح `REVIEW_OFFLINE_UNAPPROVED.html` بالمتصفح.
- اعمل **دون إنترنت**؛ الصور هي نفسها ملفات PNG الناتجة دون تعديل، والواجهة لا تستخدم API أو اتصال شبكة.
- اختر صفحة، وقارنها **مع أصل موثوق مستقل** صفحةً صفحة؛ ليس فقط معاينة PNG وحدها.
- دقق **الحروف والحركات والوقف وأرقام الآيات والزخارف وترتيب الكلمات والأسطر والصفحات والحواف والقص**.
- سجّل الفروقات أو الأخطاء في مربع الملاحظات، وعلّم الصفحة بأنها تحتاج إصلاحًا عندما يلزم. لا تضغط إقرار المقارنة إذا لم تراجعها.
- بعد كل دفعة استخدم زر `تصدير تقدم المراجع JSON`. لا تعتمد على `localStorage` وحده. للاستئناف استورد JSON في نفس نسخة الصور.
- ينفذ مراجعة ثانية شخص **مستقل**، باستخدام نسخة نظيفة من المجلد وتقرير منفصل.

## قواعد الاعتماد
1. **604/604** صفحات خضعت لمراجعة بشرية مستقلة من مراجعَين مؤهلين، مع هوية واضحة وسجل منفصل لكل منهما.
2. المراجعان يقارنان الصور بالأصل نفسه، ولا يكتفي أي منهما بالاطلاع على إقرار الآخر.
3. كل صفحة لها بصمة PNG منفردة مثبتة، وأي تغيير للصورة يفرض مراجعة جديدة.
4. جميع الملاحظات تُحل قبل الاعتماد، ولا يجوز تخطي صفحة بسبب ضغط الوقت.
5. إقرارات JSON المصدّرة هي *سجلات متابعة بشرية*، وليست شهادات تلقائية أو بديلاً عن توثيق الهوية والمراجعة.
6. لا نُصدر `approved_manifest.json` ولا نثبت `INDEPENDENTLY_APPROVED_MANIFEST_SHA256` إلا بعد مراجعة وتوقيع مستند مستقل، ثم اختبار المحتوى داخل APK الموقّع.
7. تبقى ميزة التسميع الآية بالآية معطّلة حتى تُعتمد خرائط آيات مستقلة. لا نعتمد على OCR أو ذكاء اصطناعي لاستنتاج مواضع الكلمات.
