# القرآن الكريم | Al-Quran-Al-Kareem

تطبيق Android للمصحف الشريف، **بلا إنترنت بالكامل**، قائم على دقة مصدر المصحف قبل المظهر البصري.

> **قاعدة إصدار مُلزِمة:** لا تعديل لأي حرف أو كلمة أو حركة أو علامة أو ترتيب في القرآن الكريم. لا نضع بيانات قرآنية مولدة أو OCR. يُقبل فقط مصدر مجمع الملك فهد المطابق للبصمة المنشورة و604 صور متطابقة المصدر. لا ندّعي وجود شهادة مصادقة مؤسسية؛ التواصل الخارجي متوقف بطلب صاحب المشروع.

## ترتيب التنفيذ (ملزم)
1. اعتماد مصدر صفحات مصحف المدينة (حفص عن عاصم)، 604 صفحات وحقوق استخدامها وبصمات الأصول ومراجعتها.
2. قارئ Android يعرض المصحف المعتمد محليًا بصفحة عمودية وصفحتين أفقيتين بالترتيب الصحيح.
3. وضع **التسميع الذاتي البصري فقط**: ستر الآيات وكشفها واحدة تلو الأخرى فوق الصفحة دون تعديل الأصل، بعد مراجعة خرائط مواضعها.
4. محرك Page Curl واقعي بطيّ الورق والأضواء والظلال وتتبع الإصبع والماوس.
5. أدوات Liquid Glass رصينة مختفية افتراضيًا، ودعم القراءة الغامرة والثيمات الآمنة.
6. الفهرس والبحث المحلي (ببيانات موثقة) والعلامات والورد والختمة اليدوية.
7. تدقيق المصحف، اختبارات offline والأجهزة، APK موقّع.

## المستبعد نهائيًا من v1
لا تشغيل تلاوة صوتية أو ميكروفون؛ لا حفظ ذكي ولا متشابهات ولا متابعة طلاب؛ لا مزامنة ولا إعلانات ولا تحليلات شبكية. الضغط على الكلمة لتفسيرها **فكرة لاحقة بعد v1 فقط**.

## 📲 تطبيق Android واحد قابل للتحديث

معرّف التطبيق النهائي الثابت: `app.alquran.kareem`. الإصدار الأول المخطط: `1.0.0` ورقم `versionCode=100`؛ كل تحديث قادم يحتفظ بالتوقيع نفسه ويرفع رقم الإصدار. **لا مزيد من التطبيقات المنفصلة أو توقيعات Debug المتغيرة**.

الوظائف المنجزة في الكود: عرض 604 صفحة أصلية دون إنترنت؛ حفظ موضع القراءة، العلامات، الختمة اليدوية، عرض صفحتين للأجهزة اللوحية، التنقل باللمس والماوس والأسهم، فهرس **114 سورة و30 جزءًا و60 حزبًا**، والانتقال إلى مرجع آية مثل `2:255`. ميزة التسميع البصري التدريجي قيد اختبار Android؛ لا ندّعي أنها تكشف الآيات بحدودها الدقيقة.

**التوقيع النهائي:** بنيته جاهزة في `.github/workflows/build-stable-signed-update.yml`، لكنه يرفض إصدار APK دون مفتاح توقيع إنتاج دائم وشهادة ثابتة في GitHub Actions secrets. راجع [إعداد الإصدار والتحديث الآمن](docs/RELEASE_SIGNING_AND_UPDATES.md). لم يتم حتى الآن التحقق من وجود مفتاح توقيع إنتاج متصل؛ **لا يوجد APK نهائي موقّع تم تسليمه أو اعتماده للتحديث**.

**مهم:** المعاينة التاريخية من إصدار `.preview` لا يمكن ترقيتها مباشرة إلى معرّف الإنتاج بسبب اختلاف الحزمة والتوقيع؛ هذا انتقال واحد فقط. ولا نُوزع مزيدًا من APKs التجريبية.

## مساهمة آمنة
لا ترفع ملفات توقيع، مفاتيح، أسرار أو نسخة مصحف غير معتمدة. GitHub CI يفحص السياسات البرمجية فقط؛ هذا لا يغني عن مراجعة النص القرآني.
